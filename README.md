# fingerprint_spoofing
The aim of this project is to create a classifier that can effectively differentiate between authentic and manipulated fingerprint images by leveraging various machine learning algorithms. These fingerprint images are initially transformed into a lower-dimensional space, typically reduced to just 10 dimensions to ensure computational efficiency. It’s important to note that these reduced dimensions don’t hold any specific physical meaning. The original dataset comprises 7 distinct classes. However, for the purposes of this project, we have simplified it by binarizing the dataset. We have grouped all manipulated (spoofed) fingerprint samples into class 0 and all genuine (authentic) fingerprint samples into class 1. In this project, we will conduct training on various classifiers and explore different hyperparameter combinations using our training dataset. This approach will allow us to assess the performance of the top-performing classifier on our test dataset and verify the suitability of our choice.
